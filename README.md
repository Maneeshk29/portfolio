# Maneeshkumar Lillyprabhu: Portfolio

Personal portfolio: software engineering, data engineering, data science and entrepreneurship.

Live: https://maneesh-lillyprabhu.vercel.app

Built with Next.js, Tailwind CSS, shadcn/ui and Magic UI, from the open-source [portfolio template by Dillion Verma](https://github.com/dillionverma/portfolio) (MIT).

## Edit content

All content is in `src/data/resume.tsx`.

## Run locally

```sh
pnpm install
pnpm dev
```
